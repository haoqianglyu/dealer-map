# 小区名归一化 bug（2026-10-22）

范围：只修 `src/geo/normalize.js` 把小区名本身截错/剥错的问题；匹配策略（模糊、同音、母小区、POI 类型过滤）不动。
方法：生普账号只读拉取全部 702 个项目，对 `name` 与 `customer_address` 离线跑新旧 `communityName`，逐条检查每一种不同的变换（户号数字已打码，只看小区名部分）。
回归测试：`npm test`（`tests/normalize.test.mjs`，覆盖下列全部例子和原有正确行为）。规则版本 `NORMALIZE_VERSION = 2`，本机缓存 `CACHE_VERSION` v7 → v8。
