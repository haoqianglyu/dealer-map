## 1. Top 10（按 影响 ÷ 工作量 排序）

### 1. 【P0】告警轮询失败一次，整屏变成「假正常」—— 要像在线状态那样「沿用旧数据 + 标未更新」
**现象（60-offline-1350.png）**：断网 66 s 后下一次轮询失败，`loadAlarms` 的 catch 把 `alarms` 清空 → 告警面板整块空白只剩一行灰字「告警加载失败，稍后自动重试」；**地图上 绿地香颂 的红圈 + 「3 告警」角标同时消失，变成青色正常圈**；状态行写「告警 — 更新」。恢复网络后要等下一个 60 s 周期才回来（实测 3 s 后仍是错误态，约 50 s 后恢复）。在线状态的处理是对的（沿用 + 「在线状态 05:17 未更新」），告警却走了相反的策略。展厅里 Wi-Fi 抖一下，屏幕会用一分钟告诉老板「没有告警」。
**为什么**：代码注释写「出错时不留旧数据」是为了避免过期计数和错误提示同时出现 —— 但"过期 1 分钟的 23 条告警"远比"0 条"更接近真相。
**规格**
- `loadAlarms` 失败：保留 `alarms.value`、`alarmUpdated` 不变，新增 `alarmStaleSince = alarmStaleSince || Date.now()`；成功时清零。
- 状态行：stale 时「告警 05:17 **未更新**」（`--dm-warn-text`），与在线状态同一写法；去掉「告警 — 更新」这种句子（`alarmUpdated` 为空时整段不显示）。
- 面板：stale < 5 min 什么都不变；5–30 min 在列表顶部加一行 28 px 灰条「自 05:17 起无法更新告警」，列表行 `opacity: .7`；> 30 min 才清空 + 现有错误文案。403（真无权限）保持立即清空。
- 退避重试：失败后 10 s → 20 s → 40 s（上限 60 s）单独重试告警，而不是等整周期；`window 'online'` 事件与 `visibilitychange → visible` 立即 `refreshStatus()`（在线状态同样受益）。
- 地图角标 / 红圈由 `alarmStateMap` 派生，数据不清就不会掉。
- 测试：`tests/alarm-stale.test.mjs`：失败 1 次不清数据；5 min 标 stale；30 min 清；成功后 stale 归零。
**工作量**：半天。

### 2. 展厅待机巡览（attract mode）—— 没人碰时它应该自己讲故事
**现象**：空闲 20 s 采样：60 fps、0 长任务、0 日志 —— 也就是说什么都没发生。只有告警行跑马灯和脉冲环在动。展厅里这是一张静止海报；老板带客人站到屏前，看到的是上一个人留下的任意缩放级别（本轮退出前就停在 z16 的 绿地香颂 弹窗上）。前四轮都把它列为「未做 P2」，现在它是剩余项里影响最大的。
**规格**（新 composable `useTour.js`，DealerMap 调用 AmapView 暴露的 `flyTo / zoomTo(district) / openCommunity / closePop`）
- 触发：120 s 内无 pointerdown / keydown / wheel / touchstart（捕获阶段监听）且：无用户打开的弹窗与下拉、不在详情页、`document.visibilityState === 'visible'`、不在主题切换中。`?tour=0` 禁用、`?tour=1` 立即开始、`localStorage.dm_tour_idle` 可改秒数。
- 一轮脚本（约 75 s，循环）：
  1. 回当前筛选城市的城市视野（`fitCity` 同一路径），点位模式，停 10 s；
  2. 告警数最多的 3 个区县，每区：`zoomTo(district)`（与点区县同一逻辑，让出侧栏）停 6 s；若区内有**已定位的进行中告警小区** → 飞到 z16 打开弹窗并展开告警（`focusAlarm` 同一路径）停 8 s → 关弹窗；
  3. 回城市视野切 热力·项目 8 s → 热力·告警 8 s → 切回点位。
- 运动：全部飞行 `setZoomAndCenter(z, c, false, 900)`；镜头之间 300 ms 静止；`prefers-reduced-motion` 时不飞行，改为 immediate 切换 + 300 ms 遮罩淡入淡出。
- 提示：状态行左侧加一个胶囊「● 自动巡览中 · 触摸任意处退出」（点 `--dm-accent` 1.6 s 呼吸，胶囊高 36 px）；顶栏、图例不变。
- 退出：任意输入 100 ms 内停止：清计时器，不再调度；进行中的 900 ms 飞行让它飞完（不要急停抖动）；关闭巡览打开的弹窗；**恢复巡览开始前的模式（点位 / 热力 + 口径），不恢复视野**（用户刚碰屏幕，别把镜头抢回去）。空闲 120 s 后再次进入。
- 新告警插播：轮询发现新的进行中一级告警（id 未见过）→ 巡览中立即插播：飞到该小区 z16 开弹窗 15 s + 第 5 条的 toast；非巡览时只 toast + 列表行高亮，不动视野。
- 不做：`document.hidden` 时暂停；详情页不巡览。
- 验收：1350 / 1920 各跑 3 轮，控制台 0 错误，堆内存不涨 > 10 MB（现 53 MB）；任意触摸 100 ms 内胶囊消失且不再移动。
**工作量**：1 天（含插播）。

### 3. 登录 → 地图的连续性：现在是「勾 → 硬切 → 2.4 s 品牌罩 → 数字跳出」
**现象（51-timeline.json、54/55/57）**：点登录 0 s → 1.8 s 接口返回 → 勾 0.3 s → 3.0 s 路由切换（无过渡）→ 罩「正在加载项目数据…」到 5.4 s → 首批 7 个标记 + KPI 数字从 30 滚到 595（1.4 s）。罩期间顶栏已经在：品牌位是**空白占位 + 竖线**（logo 5.2 s 才出现，而 `defaultBrand()` 一开始就知道是生普）、城市下拉写「全部城市」而 URL 里是 `region=320200`（5 s 后才变「无锡市」）、KPI 副标写「**无锡市 / 共 0**」再变「已加载 0 / 596」。登录页那片暖光一下子消失，换成黑底 + 小转圈，两段等待没有接上。
**规格**
- 预热：`submit()` 拿到 token 后**立刻**（不等 300 ms 勾）并行发 `me()`、`loadOverrides/loadSeed/loadShared`、`loadAmap()`，结果放模块级 promise（`api/prefetch.js`），`DealerMap.onMounted` 优先复用。高德 JS 甚至可以在登录页 `onMounted` 就开始加载（Key 本来就在前端，不依赖登录）。预期首批标记从 5.4 s 提前到 ~3.5 s。
- 过渡：`App.vue` 的 `router-view` 加 `<transition name="xfade" mode="out-in">` 250 ms；罩背景复用登录舞台：把 `stage__lights` canvas 抽成 `LightsCanvas.vue`（登录页 / 罩共用，参数：中心、透明度），罩期间灯光继续呼吸，瓦片就绪后 400 ms 淡出露出地图 —— 老板看到的是"灯光图长出了真地图"。
- 罩文字改进度：有 `totalVisible` 后写「已加载 120 / 596 个项目」，没有时保持现文案。
- 假状态三处：`kpiSub` 在 `allProjects.length === 0` 时返回空；城市下拉在 `cityOptions` 为空时用 URL 的 region 查 `districts.json` 直接显示「无锡市」；品牌占位改为 `defaultBrand()` 的 logo 0.35 透明度，资料返回后淡到 1（而不是空白 → logo）。
**工作量**：1 天。

### 4. 「全部城市」时视野外 / 侧栏后面的项目没有任何提示
**现象**：1350 全部城市：常熟 1 / 太仓 2 / 嘉定 3 被侧栏盖住（截图里「1 常熟」只露一半），上海 7 个区、北京 2、泰兴 2、扬中 1、江都 2、宁波 1、成都 / 重庆 在视野外；1920 实测 16 个区县标记在界面后或视野外（`hiddenBehindUi` 列表）。首屏按主城市区县适配是对的（第二轮定的），但「全部城市 702」里有 107 个项目老板永远看不到也不知道在哪。
**规格**
- 边缘胶囊：`moveend / zoomend` 后 150 ms 节流，把当前级别的标记里**不在可视区（扣掉 `avoid`）**的按 8 个方向归并，最多 4 个胶囊：「→ 上海 18 · 苏州 12」「↑ 泰州 3」「↗ 南通 1」；胶囊 36 px 高、贴地图边 16 px、按方向放在对应边的中点附近，与图例 / 状态行 / 弹窗避让；200 ms 淡入淡出。
- 点按 = `fit` 到该组的 bounds（含当前视野，所以是"拉远到两边都看得到"），不是跳走。
- 只在有项目被遮 / 在视野外时显示；筛选单城市时也适用（1350 下常熟 / 太仓那种被侧栏盖住的）。

**工作量**：半天。

### 5. 新告警到达没有即时反馈（与第 2 条的插播共用）
**现象**：轮询拿到新的进行中告警时只有列表行多一个 `fresh` 小点和标记脉冲；面板滚在下面的话根本看不到。展厅的核心承诺是「告警来了屏幕会告诉你」。
**规格**
- toast：顶栏下方居中，44 px 高红边玻璃胶囊「● 新一级告警 · 绿地香颂 · 空气处理机(122) 通讯故障」8 s，点按 = `focusAlarm`（已有）；同时列表把该行滚到可见并用已有 `flash` 样式闪 3 次；多条合并「3 条新一级告警」点按滚到列表顶。
- 判定：`alarms` 新旧 diff，`id` 未见过 且 `isActiveAlarm` 且 `ts > 上次轮询时刻 − 5 min`（避免首轮全量当新告警）。首轮不提示。

- 两套主题：`--dm-alarm` 边 + `--dm-panel-solid` 底 + `--dm-text`。
**工作量**：半天（不含声音 2 h）。

## 2. 快赢（每条 < 30 分钟）
