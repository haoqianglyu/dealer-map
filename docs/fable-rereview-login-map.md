# 登录页 + 地图页 第二轮评审（Fable，2026-10-21，实机操作）

对象：分支 `wip-polish` @ 672728b，本地 dev（worktree /tmp/dm-fable-rr，端口 8095，/api 代理同仓库 vite 配置），生普测试账号。
方式：**真实 Chrome（CDP 9333 自动化实例，非 headless）**，真实鼠标事件（move/down/up/wheel/drag）+ 键盘，deviceScaleFactor 2；
视口 1350×700（笔记本）为主，1920×1080、2560×1440 现场 resize 复查。截图在 `/tmp/dm-rr/`（login-*、map-1350-*、map-1920-*、map-2560-*）。
实测流程：错密码 → 对密码 → 首屏加载计时 → 城市视图 → hover/点击区县 → 滚轮/拖拽 → 小区弹窗（展开告警、×）→ 城市下拉（鼠标 + 键盘）→ 告警列表点击 → 热力 项目/告警 → 图例 ? → 现场 resize 三档 → 退出 → 回登录页。

## 1. 一句话结论

**这一轮是质变：底图安静了、标记变成细环 + 白字、侧栏一屏放下、登录页有了品牌。** 大方向全部落地，剩下的是"用起来"才会碰到的几处：
首屏的 loading 罩比数据慢 2 秒多；顶栏 / 状态行太透导致地图上的字和气泡从界面文字底下透出来；近景（zoom ≥ 12）底图 POI 又亮回来跟标记抢；弹窗 × 用真实鼠标点了一次没关上（待复现）；2560 下标记 / 弹窗不随界面放大。

## 3. 本轮实机新发现

**3-1 首屏 loading 罩比数据慢 2.5 s（每次登录都会感到"慢"）**
计时（从点登录起）：成功勾 5.7 s → 路由 6.2 s → 地图 canvas 7.7 s → 首批标记 + KPI 8.5 s → 告警 9.2 s → **boot 罩消失 10.6 s**。
t+3 s 时 15 个标记已经画出来，罩还盖着；罩是靠 AmapView 挂载后 2.5 s 的兜底定时器收掉的（`complete` 没触发）。用户看到的是"转了 4.5 秒"，其实 2 秒就好了。

**3-2 顶栏 / 状态行太透，地图内容从界面文字底下透出来**（1350 与 1920 都有）
- 「南通市」dm-city 标签透在时钟日期「2026-10-21 周三」正下方；「靖江市 1」气泡上半截在顶栏渐变里。
- 「吴中区 9」气泡压住右下状态行「已定位 229 / 449 小区 …」，文字不可读。
- 状态行本身无底色，任何路网 / 灯光经过都发糊。

**3-3 近景（zoom ≥ 12）底图 POI 重新"抢亮度"**
点位模式 12–14 级：几十个亮青色 POI 名（含镇名、景区名、底图的「新吴区」）和上百个小区圈同屏，第一轮说的"全屏都在发光"在近景又回来了。热力近景更明显：暖光弱、POI 亮。自定义样式不可用（付费），但 `setFeatures` 还有空间。

**3-4 弹窗 × 真实鼠标点击未关闭（一次，待复现）**
流程：点小区 29 → 弹窗 → 点「4 条一级告警 ▸」展开（成功，弹窗重绘）→ 真实 mousedown/up 在 ×（屏幕 787,79）→ `.dm-pop` 仍在。
可疑点：× 中心离顶栏底边只有 4px；或 `info.setContent` 重绘后高德 InfoWindow 内部拦了 mousedown。点地图空白可关，所以不是死锁，但"点 × 没反应"是用户最先骂的那种。

**3-5 2560×1440：界面放大 1.33，地图层没放大**
侧栏 / 字号都按 1.33 走了，小区圈仍是 26–40px、弹窗仍 360px、区县数字仍 20px——在 2560 的屏上像撒了一把芝麻。

**3-6 焦点态**
- 登录页「记住账号」checkbox 的 focus 是浏览器默认 `auto 1px rgb(0,95,204)`，深底上看不见。
- 密码眼睛按钮 focus 只有 6% 白底，没有描边。
- 其它（输入框 3px 青晕、登录按钮 2px 白描边、下拉按钮）都对。

**3-7 1350 下告警面板只看 4 行**
compact 时告警 268px、各区项目 221px；各区项目 7 行条形图下面留白，告警却只露 4 行（第 5 行被切一半）。注意力分配倒了。

**3-8 小问题**
- 登录页「生普舒适家」出现三次（logo、副题、页脚）。副题里的品牌名可删。
- 顶栏日期 9.4px（见上）。
- 滚轮缩放一格 = 1 级，从区县视图到小区视图跳感明显（AMap 默认），拖拽顺滑。
- 城市下拉面板 238×196，「更多城市」点开后面板变高但不滚动，16 项在 1350 下还装得下，OK。

## 4. 最终优先级清单（精确规格）

### P0

**P0-1 boot 罩随首批标记消失**（§3-1）
- `AmapView`：`emit('ready')` 条件改为「`complete` 事件 **或** 首次 `renderMarkers()` 后 `markers.length > 0` **或** 挂载后 1200 ms」三者最早者。
- `DealerMap .boot` 退出用 `transition name="fade"` 300 ms（已有），罩的 `background` 改为 `rgba(6,16,36,0.92)`，退出时地图已在下面，不会黑→蓝闪。
- 目标：路由后 ≤ 2.5 s 看到地图 + 标记（现在 4.5 s）。

**P0-2 弹窗 × 必须可靠**（§3-4）
- `.dm-pop__x` 改成 `pointerdown` 直接 `info.close()`（不走冒泡到 `el` 的 click），并 `e.stopPropagation()`；尺寸 26 → 32×32，右上 `top: 6px; right: 6px`。
- `openPopover(c, keep=true)` 重绘后重新 `requestAnimationFrame(avoidUi)`，并保证 `avoid.top = 88 × s`（与顶栏渐变等高），弹窗顶边不再钻进顶栏。
- 复现脚本：`tests/marker-click.sh` 加一步「展开告警 → 点 × → 断言 `.dm-pop` 不存在」。

### P1

**P1-1 顶栏 / 状态行底色**（§3-2）
- `.topbar` 背景 `linear-gradient(180deg, rgba(4,11,24,0.92) 0, rgba(4,11,24,0.80) 64px, rgba(4,11,24,0) 96px)`，高 96px（内容仍 64px）。
- `.status` 加 `padding: 3px 10px; background: rgba(4,11,24,0.72); border-radius: 6px; backdrop-filter: blur(6px)`。
- `.dm-city` 标签 `zIndex` 不变，但 `renderLabels()` 过滤掉投影到屏幕后落在 `avoid` 区域内的城市名（`map.lngLatToContainer` 后 y < avoid.top 或 x > width − avoid.right 的不画）。

**P1-2 近景底图再压一次**（§3-3）
- `applyFeatures()` 三档：`district: ['bg','road']`；`community (12–13.9): ['bg','road','building']`；`named (≥14): ['bg','road','building','point']`。
- 热力模式任何级别都不带 `point`（灯光自己就是信息）。
- 代价：12–14 级没有地名参照，但我们的小区圈密度足够定位；需要地名时再放大一级即有。

**P1-3 地图层随界面缩放**（§3-5）
- `AmapView` 新增 `scale` prop（= uiScale，1350 时 0.85 不缩小，取 `Math.max(1, scale)`）。
- `markerHtml` 的 `--size`、`.dm-mk__n` 字号、角标、`.dm-pop` 宽度（360 → `360 × k`）、`.dm-pop` 字号都乘 k；用根节点 `style="--k: 1.33"` + CSS `calc()` 实现，避免重建标记。
- 2560 期望：区县圈 59–117px、数字 27px、弹窗 480px。

**P1-4 compact 模式把高度让给告警**（§3-7）
- 1350（compact）：各区项目面板改为「前 5 区 + 全部 n」，高度 221 → 170；告警面板 268 → 319，可见 6 行。
- 告警行高 compact 下 48 → 46。

**P1-5 焦点态补齐**（§3-6）
- `.remember input:focus-visible { outline: 2px solid #35d4ff; outline-offset: 2px }`。
- `.eye:focus-visible { box-shadow: 0 0 0 2px #35d4ff inset }`。
- 全站统一规则：`:focus-visible` 一律 2px `#35D4FF`（按钮 / 行 / 列表项），不要再出现浏览器默认蓝。

**P1-6 最小字号**
- 顶栏日期 11 → 12px；1350 下为 10.2px。全站 ≤11px 的只允许比例尺（高德控件）。

### P2

- 登录页副题去掉前缀品牌名：「实时项目分布 · 一级告警 · 设备运行」；页脚保留。
- 「记住账号」首次访问默认勾选（展厅 / 经销商场景几乎都是同一账号）。
- 滚轮缩放：`new AMap.Map({ zooms: [3, 18], scrollWheel: true, jogEnable: true })` 已是默认，若老板嫌跳，可监听 `wheel` 以 0.5 级为步长调用 `setZoom(z ± 0.5, false, 200)`。
- 点位 ↔ 热力切换：标记层 200 ms 淡出 → 暖光 300 ms 淡入（第一轮 P2-1，仍未做）。
- 热力近景（≥14）暖光最小半径再提一档，否则在 POI 关闭后画面偏空。
- 城市下拉「更多城市」展开后面板高度变化加 160 ms `height` 过渡。
