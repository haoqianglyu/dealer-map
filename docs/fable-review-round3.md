## 5. 优先级清单（精确规格）

### P0

**P0-1 地名只画一份：按级别分工，高德的字和我们的字不同时出现在同一类地物上**（§3-1、§3-2）
判断：高德 `setFeatures` 只有 bg / road / building / point 四档，`point` 里区县名、城市名、POI、（部分样式的）路名是一体的，**没有办法只留路名去掉区县名**；自定义样式（可逐类关注记）是付费项。所以要么高德画、要么我们画，按级别切：

| 级别 | 高德 features | 我们画的文字 |
|---|---|---|
| district（z<12） | `['bg','road']`（回到第二轮） | 城市名 `.dm-city` + 气泡下区县名（现状）；**另加一份静态邻近城市表**（长三角 ~25 个地级市的名字 + 经纬度，放 `src/data/cities-context.json`），用同一 `.dm-city` 样式画，补回 z7–9 的「南京 / 合肥 / 杭州」方位感。有气泡的城市仍跳过。 |
| community（12–14） | `['bg','road','building','point']` | 不画（现状）。高德的区县名 / POI 在这一级是唯一的文字，不重复。 |
| named（≥14） | `['bg','road','building','point']` | 保留 `.dm-mk__label`（它是项目口径的小区名，高德不一定有），但把我们的字**挪进标记**：把小区标记在 ≥14 级改成「圆 + 名字」的胶囊（`.dm-mk--named { border-radius: 999px; padding: 0 10px 0 4px }`，名字在圆右侧同一行），这样高德的同名 POI 读起来是底图注记，我们的是数据标签，不再是两行一样的字叠着。 |

- 热力模式：district 级同上（`['bg','road']` + `.dm-hlabel`）；≥12 与点位一致。
- `cityLabels` 的 `near()` 过滤改成"附近有**任何**区县气泡"而不是只看当前筛选的 `props.districts`：把全量区县中心（`districts.json` 已有）作为 `avoidPoints` prop 传进去，无锡市筛选时「苏州市」「常州市」仍然只由我们画一份（高德已关）。
- 路名：`darkblue` 预设不出路名。切到 `amap://styles/dark`（有路名、注记为灰而非青，也顺手解决第二轮 P1-2 的"POI 抢亮度"），底色差异用现有 `.amap` 遮罩补；若老板坚持 darkblue，路名这条验收要明确放弃。
- 验收：z7.3 / 9.9 / 11（全部城市 + 无锡市）/ 12.5 / 14.5 / 16，点位 + 热力，每张截图里任一地名只出现一次；z≥13 能看到路名。

**P1-3 跑马灯先去重、再少动**（§3-4）

- 可选（展厅模式更静）：不滚，改为每 6 s 整行在「设备」与「内容」两段之间淡切。

**P1-4 归一化：行政区前缀**（§3-5 前两组）
- `communityName()` 末尾：若结果以**已知**市名 / 区县名 / 镇名开头（`districts.json` + 城市表 + 一份 ~60 个镇名表），剥掉前缀并把它作为 `hint.region` 返回（`{ name, region }` 或新函数 `communityParts()`）。
- `geoQuery()` 真正实现注释里的事：`region` 存在时用它替代 `cityName/districtName`（「太仓市天悦湾」→ `苏州市太仓市天悦湾`，`city=太仓市`）；否则现状。`NORMALIZE_VERSION` 3、`CACHE_VERSION` v9，只重查 key 变化的 ~20 个。
