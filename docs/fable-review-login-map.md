# 登录页 + 地图页 设计评审（Fable，2026-10-21）

评审对象：https://dealermap.haoqianglyu.com 线上版（生普测试账号），1920×1080 与 1350×700 两档实际截图，
对照源码 `src/views/Login.vue`、`src/views/DealerMap.vue`、`src/components/AmapView.vue`、`warmLights.js`、`TechPanel.vue`、`CityPicker.vue`。
截图留在 `/tmp/dm-review/`（login-1920 / map-1920-city2 / map-1920-heat-projects / map-1920-heat-alarms / map-1920-popover / map-1920-side-bottom / map-1920-dropdown / map-1350-city / map-1350-heat-projects / map-1350-popover 等）。

---

## 1. 总体判断

**现状一句话：功能齐、数据对、但视觉停留在 2018 年 DataV 模板的"科技蓝大屏"水平，离"高端产品"差一个档次。**
好的地方要先说清楚：数据结构（区县气泡 → 小区 → 弹窗 → 详情）是对的；告警用红色、10 天进行中/总数的口径清楚；
自定义城市下拉比原生 select 强很多；热力"暖光"的概念方向是对的，比 ECharts 彩虹热力高级。

**最拖后腿的一件事：地图层和界面层在"抢亮度"，没有主次。**
高德 `darkblue` 底图自带的区县名、POI 名、车站名全是亮青色（和我们的标记同色同亮度），
标记又是 85% 实心饱和青色 + 发光，侧栏是 90% 不透明的深蓝框 + 角标边框 + 渐变字 + 文字投影。
结果是全屏都在发光，眼睛不知道先看哪里：1920 城市视图里 "惠山区 / 锡山区 / 新吴区 / 滨湖区" 四个名字每个出现两次
（底图一次 + 我们的标签一次），"新北区" 标签压在底图 "常州市" 上，1350 下 "武进区" 气泡被左上角比例尺盖住。
一个高端大屏的底图应该是"安静的舞台"，只有数据在发光。这一点不解决，其它都是修饰。

第二件：**侧栏在 1920×1080 的设计稿尺寸上就装不下**（各城市列表 24 行，整列要滚动），在 1350×700 只能看到第三块面板的两行。
大屏不该出现滚动条，这说明信息没有做取舍。

第三件（功能性但影响"完美"的体感）：**退出登录后地图没有销毁**。`App.vue` 对 `DealerMap` 做了 `keep-alive`，
`logout()` 只是 `router.replace('/login')`，重新登录后上一次的地图视角、甚至打开着的小区弹窗（含客户项目名）直接复现。换账号登录时这是数据泄露面。

## 2. 登录页：重设计方向

### 现状问题（具体）
- 背景 `bg1.jpg` 是 **7251×4018、7.1 MB** 的"太空看地球"图库照片。与无锡、暖通、生普没有任何关系；首屏 7 MB 在展厅盒子/4G 热点上会白屏几秒。这张图还被 `.screen` 当地图页背景引用（完全被地图盖住，白加载）。
- 没有任何品牌：登录页出现的是通用名"项目分布大屏 / PROJECT DISTRIBUTION MAP"，生普 logo 登录后才出现。老板看到的第一屏不是他的品牌。
- 标题两侧的青色小圆点、英文副标、`linear-gradient` 渐变文字、蓝→青渐变按钮、边框外发光——这些全是模板年代的符号，叠在一起就显得廉价。
- 零动效：没有进场、没有焦点动画、没有提交反馈（按钮只是文字变"登录中…"）、没有错误动画。
- 1350×700 下表单不随 `useScreenScale` 缩放，和地图页比例不一致。

### 方向：用他们自己的数据做"品牌一刻"
登录页左侧不要放照片，放一张**由 `public/geo-seed.json`（现已移到 `worker/data/geo-seed.json`，登录后经 `/geo-shared/seed` 下发）里 449 个小区坐标实时绘制的暖光图**
（直接复用 `warmLights.js` 的三层径向渐变 + `lighter` 叠加，简单墨卡托投影到 canvas，不需要加载高德、不需要登录）。
含义是"生普已经点亮了无锡 700 多个家"，这是只有这家公司能用的画面，而且和登录后的热力模式视觉连续。
如果担心 seed 文件带坐标信息外泄，可以构建期把它渲染成一张 1920×1080 的 webp（≤ 200 KB）。

### 版式（1920×1080 设计稿，走同一个 `useScreenScale`）
- 左 62%（0–1190px）"品牌舞台"，右 38%（1190–1920）表单区；1350×700 时同比例缩放，不改布局。
- 页面底色 `#040B18`；舞台上叠一层暗角 `radial-gradient(60% 80% at 38% 55%, rgba(27,98,216,0.16), transparent 70%)`；
  暖光图整体透明度 0.85，中心在无锡市区（约舞台 x 55%、y 52%），灯光做 4 s 周期、±8% 亮度的缓慢呼吸（`prefers-reduced-motion` 时静止）。
- 舞台左上 (96, 72)：生普 logo，高 44px，白色（现有 filter 方案）。
- 舞台左下 (96, 1080−160)：
  - 标题 40px / 1.2 / 600 / `#F2F7FF` / 字距 0：「项目分布与运行告警大屏」（"大屏"二字可去，看老板叫法）
  - 副题 16px / `#8FB0D0` / 字距 0：「无锡 · 五恒系统 · 实时项目分布与一级告警」
  - 不要英文副标、不要圆点装饰。
- 底部 (96, 1080−48)：12px `#4F6E93`「© 生普舒适家 · v1.x · 技术支持：xxx」。

### 表单卡（右侧垂直居中）
- 宽 420px，内边距 40px，圆角 14px，背景 `rgba(8,20,44,0.72)`，边框 1px `rgba(120,170,255,0.16)`，
  `backdrop-filter: blur(16px)`，阴影 `0 24px 64px rgba(0,0,0,0.45)`。**不要发光边框、不要 inset glow、不要角标。**
- 卡内标题 22px / 600 / `#F2F7FF`「登录」，下方 13px `#8FB0D0`「使用平台账号登录」；标题到首个输入框 28px。
- 标签 13px `#8FB0D0`，标签到输入框 8px；输入框高 48px，圆角 8px，背景 `rgba(255,255,255,0.04)`，边框 1px `rgba(255,255,255,0.10)`，文字 15px `#E8F4FF`，占位 `#4F6E93`；
  focus：边框 `#35D4FF` + `box-shadow: 0 0 0 3px rgba(53,212,255,0.18)`，过渡 120ms。两个输入框间距 20px。
- 密码框右侧加"显示/隐藏"眼睛图标（展厅里常有人输错）。
- 按钮高 48px，圆角 8px，**纯色** `#35D4FF`，文字 `#04121F` 16px 600 字距 2px；hover `#5FDDFF`；active `transform: scale(0.98)`；
  提交中：文字淡出、换 18px 圆环 spinner；成功后按钮变 `#00E2A1` 打勾 300ms 再跳转。输入框到按钮 28px。
- 错误：显示在对应输入框下方 13px `#FF8A7A` + 14px 图标，卡片做 240ms 的 ±6px 横向 shake；不要用红字一段放在按钮上面。
- 进场：卡片 `opacity 0→1, translateY 12→0` 320ms ease-out；舞台暖光延迟 200ms 从 0 淡入 800ms。
- 登录成功 → 地图页：路由过渡 400ms 交叉淡化，暖光图淡出的同时地图淡入（视觉上像"从登录页的灯进入真实地图"）。
- 记住账号：`localStorage` 存手机号（不存密码），下次只需输密码；展厅盒子可配 `?kiosk=1` 自动用环境变量的只读账号登录。

## 3. 地图页：按优先级的具体改动

### P0（不做这些，别的都白做）

**P0-1 自定义高德底图样式，把底图"压黑"**
- 为什么：现在 `amap://styles/darkblue` 的区县名、站名、POI 全是 `#5B9CFF` 级别的亮青色，与标记同色；热力模式又切到 `amap://styles/dark`（灰黑 + 灰色标签框），整个产品色调瞬间从海军蓝变成水泥灰，像两个产品。
- 做法：在高德控制台做一个自定义样式（两种模式共用，热力模式只靠现有 canvas 的 `rgba(14,14,16,0.28)` 压暗层，**不要再切样式**）。参考值：
  - 陆地 `#06101F`，水域 `#040A16`，绿地 `#07131F`，建筑面 `#081426`
  - 高速 `#152A4D` 宽 1.5，主干 `#0F1F3A`，次干 `#0B1830`，支路隐藏（zoom<14）
  - 市级地名 14px `#6F8FB8`，区县名 12px `#3D5F8A`（我们自己的标签才是亮的），镇/村名、交通站点、POI 在 zoom<14 全部隐藏，zoom≥14 只保留小区/住宅类 POI，颜色 `#3D5F8A`
  - 行政边界 `rgba(120,170,255,0.18)` 虚线
- 这一条同时解决"每个区名出现两次"和"标签打架"的大部分问题。

**P0-2 标记（气泡）重做：由"实心发光球"改为"细环 + 白字"，告警只用环和角标表达**
- 为什么：现在 85% 实心青色球 + 外发光 + 深色数字，是页面里最刺眼的元素；"锡山区 63 个项目、5 条告警"整颗球变红，读起来是"63 个全在告警"。1350 下球的数字 12px 缩到 10px 看不清。
- 区县级（zoom<12）规格：直径 `clamp(44, 36 + sqrt(count)*6, 88)`px；填充 `rgba(53,212,255,0.10)`；环 2px `#35D4FF`；内阴影 `inset 0 0 18px rgba(53,212,255,0.25)`；
  数字 20px / 600 / `#FFFFFF` / 等宽数字（见 P1-1 字体）；名称 13px `#D8ECFF`，底下不用 text-shadow 而用 `paint-order: stroke; -webkit-text-stroke: 3px rgba(4,11,24,0.9)` 的描边，描边比阴影在缩放下更稳。
- 告警：环色改 `#FF4D4F`，填充 `rgba(255,77,79,0.12)`，右上角标 20px 高、`#FF4D4F` 底 `#FFF` 字 12px，**内容写"5 告警"而不是裸数字 5**（现在"63"旁边一个"5"要想一下）。1 小时内新告警保留现有 `dm-pulse` 扩散环，周期 1.6s → 2.4s，更稳。
- 小区级（zoom≥12）：直径 `clamp(26, 20 + sqrt(count)*5, 40)`，数字 13px，其它同上；小区名在 zoom≥14 才显示（现在不显示，只能靠底图 POI 猜，而 POI 又将被隐藏，所以要补）。
- 预警 `#FFC722`、离线 `#8A9BB3` 同样只改环色。

**P0-3 侧栏信息架构：一屏放下，不滚动**
- 为什么：1920×1080 上整列 ≈ 1250px，超出 1080；1350×700 只看到前两块半。`scope` 卡片、KPI "已定位/共计小区"、图例里的"定位中 x/y" 三处说同一件事。
- 预算（设计稿像素，侧栏顶 72 → 底 24，共 984px，块间距 12）：
  1. KPI 区 128px（2 行 3 列，见 P1-3）
  2. 一级告警 440px（主角，占最多）
  3. 项目分布 236px（**只放前 8 个区县**，城市行删除，"其它 n 城 · m 个"一行收尾；展开功能改为点击面板标题打开一个浮层，不撑高面板）
  4. 新增趋势 156px（年/月切换保留）
  - 合计 128+440+236+156+3×12 = 996，略超 → 新增趋势减到 144。`类别 / 状态` 从侧栏删掉，并入 KPI 副文案（如"五恒 663 · 单机版 39"），或作为 KPI 悬停提示。
- 删除 `scope` 卡片：账号名已在顶栏，"已定位 229/449 小区 · 已加载 702"挪到地图右下角一行 12px `#6F8FB8` 的状态行（见 P1-7）。

**P0-4 退出登录必须销毁地图页状态**
- `logout()` 后 keep-alive 的实例还在：重新登录（可能是另一个经销商账号）直接看到上一个账号的视角和打开的弹窗。
- 修法任选：`logout()` 时 `router.replace('/login')` 之后 `location.reload()`；或 `keep-alive` 加 `:max`/用 `include` 的动态数组在登出时置空；或在 `Login.vue` 挂载时发一个全局事件让 `DealerMap` `onDeactivated` 里 `map.destroy()`。另外 `onActivated` 回来时要 `info.close()`。

**P0-5 布局碰撞：比例尺、被侧栏遮住的标记、初始视野**
- 1350 下左上比例尺（`AMap.Scale` 放在 left 24 / top 96）正压在"武进区"气泡上；1920/1350 两档右侧边缘都能看到上海的 1/2 气泡从侧栏后面露出来，太仓的"1"隔着 90% 的面板透出来。
- 比例尺移到左下图例上方（`left: 24px; bottom: 图例高 + 44px`），颜色跟随主题（现在是高德默认白底条，非常突兀，应该用 `AMap.Scale` 的 CSS 覆盖：线 `rgba(216,236,255,0.6)` 1px，文字 11px `#8FB0D0`，无背景）。
- 初始视野不要写死 `zoom: 10.5` + `center`：首次数据到位后 `map.setBounds(区县标记外接框, false, [96, 440, 120, 72])`（上、右、下、左；右留出 380 侧栏 + 60 空隙），之后用户选城市时同样用 `setBounds` 到该市所有区县。
- 侧栏背景提到 `rgba(6,16,36,0.92)` 并且地图容器右侧 `padding`（高德 `map.setFitView` 的 `avoid` 参数）长期避开 400px，露出来的半个气泡就没有了。

### P1（决定"高级感"的层）

**P1-1 字体与字号体系**
- 数字字体：现在 `'DIN Alternate', 'Bahnschrift', monospace` 只在 macOS / Win10+ 命中，展厅 Android/Linux 盒子会落到 `monospace`（Courier）或系统中文。打包一套开源等宽数字字体（推荐 **Barlow Semi Condensed** 500/600，woff2 仅数字+符号子集 ≈ 6 KB），并开 `font-variant-numeric: tabular-nums`。中文正文打包 **思源黑体 SC** 400/500 的常用字子集（或 MiSans），保证展厅机和老板笔记本看到的是同一套字。
- 字号阶梯（设计稿像素，1350 下 ×0.85）：
  - 12：次要说明（最小，≤12 的全部提到 12）
  - 13：列表正文、标签
  - 14：列表主项、弹窗正文
  - 16：面板标题（600，字距 0，去掉渐变色，用 `#F2F7FF`）
  - 20：区县气泡数字、顶栏时钟
  - 28：KPI 数字
  - 40：英雄 KPI（项目数）
- 颜色对比：`#4F7FAE` 在深底上约 3.4:1，禁止用于 ≤14px 文字（现在登录页 hint、副标在用）；最浅的小字用 `#8FB0D0`（≈6.3:1）。

**P1-2 面板外观：去 DataV 边框，改"平面玻璃"**
- `BorderBox13` 那种斜切角 + 角标亮线是现成模板最明显的指纹，而且 svg 边框在 0.85 缩放下会出现 1px 发虚。
- 统一规格：背景 `rgba(6,16,36,0.72)`（地图可微微透出，有层次），边框 1px `rgba(120,170,255,0.14)`，圆角 10px，`backdrop-filter: blur(12px)`；
  标题行高 44px，左 16px 内边距，3×14px 圆角竖条 `#35D4FF` 作为唯一装饰，标题 16px/600/`#F2F7FF`，右侧工具（年/月切换）同一行；
  去掉 `title-tail` 渐变线、去掉 KPI 数字的 `text-shadow`、去掉标题渐变字。
- 分割线统一 `rgba(120,170,255,0.10)` 1px 实线（现在列表用虚线、面板用渐变线、行用实线三种）。

**P1-3 KPI 区**
- 2 行 3 列 → 改成 **1 大 + 4 小**：左侧「项目数 702」40px 占两行高，右侧 2×2：小区数 449、建筑面积 22.28 万㎡、房间数 7,418、设备数 11,666，数字 24px。「已定位 / 共计小区」从 KPI 删除。
- 单元格无边框，用 `rgba(120,170,255,0.10)` 分隔线；数字 `#F2F7FF`，标签 12px `#7FA3C8` 在数字**上方**（大屏惯例：先读标签再读数）。
- 筛选城市时数字做 400ms 的数值 tween（`requestAnimationFrame` 插值），这是大屏最便宜的"活"感。

**P1-4 一级告警面板（主角）**
- 标题：「一级告警」+ 红色胶囊 `#FF4D4F` 底 12px 白字「进行中 21」+ 灰字「/ 237 · 近 10 天」。
- 行高 56px，两行结构：第一行 14px `#F2F7FF` 小区名 + 12px `#7FA3C8` 区县；第二行 12px `#8FB0D0` 设备 · 内容（单行省略）。
  时间列改**相对时间**（"32 分钟前"、"昨天 13:47"，hover 显示绝对时间），12px tabular；绝对日期每行重复"10-21"是噪音。
- 进行中：左侧 3px `#FF4D4F` 竖条 + 时间前 6px 红点（1 小时内的点做 2.4s 呼吸）；已恢复/已处理：整行 55% 透明，不要再额外写"· 已恢复"在名字后面，改成右侧 11px 灰色标签。
- 删掉每行的「详情 ›」按钮（14 个一样的小按钮是视觉噪音）：整行点击 = 飞到小区并开弹窗（现在的行为），行尾一个 12px `›` 图标，hover 整行背景 `rgba(53,212,255,0.06)`；弹窗里再进详情。
- 展厅模式：无人操作 60s 后列表每 6s 自动滚一行（`scroll-behavior: smooth`），有新告警从顶部插入时整行 `#FF4D4F` 背景 20% 闪一次（600ms 淡出），并在地图顶部中央出现 4s 的 toast「新告警 · 宜兴和玺 · 二楼新风超期」，点击飞过去。
- 空状态：20px `#00E2A1` 打勾图标 + 14px「近 10 天无一级告警」+ 12px「系统运行正常」，居中；不是现在左上角一行灰字。

**P1-5 热力模式**
- 城市级（zoom 10–11）现在每盏灯外晕只有 10–30px，700 个项目看起来像一把灰尘；滨湖区 148 个项目读不出"热"。改：`zoomScale` 在 zoom≤12 时不再 <1（`Math.max(1, …)`），五档 `minPx` 提到 `22/30/40/52/68`，`peak` 不变；密度抑制系数 `crowd` 下限从 0.45 提到 0.6。
- 区县级给一个暖色的区名 + 计数标签（12px `#FFDE9E`，描边同 P0-2），不然热力模式下连"哪里是滨湖区"都没有了（底图区名按 P0-1 会变暗）。
- 告警热力：每盏灯中心加 12px `#FFF0E0` 的数字（进行中条数），灯色沿用暖红；顶部状态行显示「进行中 21 处 · 涉及 9 个小区」。
- 图例随模式切换（见 P1-6），切换模式时底图不再换样式，canvas 层 300ms 淡入淡出。

**P1-6 图例**
