## 3. 问题清单

### P1

**P1-1 胶囊级（z14–15）最重要的那个圈没有名字，且旁边的小圈压在它身上。**
复现：1350 / 1920 各一次，滨湖 z14.1 / z14.24。告警簇「38 / 1 告警」（1350）、「39 / 1 告警」（1920）是无名圆，左上有一个「1」或「2」的小圆与它相交（圆心距 29 px / 44 px，半径和 44.5 px）。z15 的 9·1·1 三件套三个全无名，只剩 29 金科蠡湖有名；z16 终态「2」「1」两个单小区圆也无名——终态不能再放大，无名就永远无名，只能点开才知道是谁。截图 `r04-z14-1350.png`、`r22-z14-1920.png`、`r05-after-38-tap.png`、`r06-after-9-tap.png`。
原因：(a) supercluster 的簇坐标是成员均值，两个簇的圆心距可以小于 radius（48 px），圆会相交；(b) `layoutLabels` 对最高优先级的项也是「胶囊矩形碰到任何圆就退化为无名圆」，被一个 1 项目的小圆否决掉了告警簇的名字。
修法（按优先）：
1. `layoutLabels`：按优先级放置时，若高优先级项的胶囊只与**更低优先级**的圆相交，保留它的名字，把那个低优先级圆标成 `demoted`（渲染为 12 px 小点 + 无数字，或干脆并入高优先级项：n、k 相加、名字加「等 k 小区」）；只在与已放置的**同级或更高**项相撞时才退化。
2. 退化之前先试「名字外挂」：圆不动，胶囊文字放到圆右侧 / 左侧（同区县名的 left / right 候选），三处都撞再退化为无名圆。终态（z ≥ 16）必须走到这一步，不接受无名。
3. 渲染前做一次「圆相交合并」：同一帧里 `dist < (S1+S2)/2 + 4` 的两项，把小的并入大的（只影响显示，点击仍按大的簇处理）。这一条也能顺手解决 2560 下不会出现、1350 下会出现的差异。
验收：三档 z14 / z15 / z16 `circleOverlaps` 为空；有告警的项在 ③④ 级一定有名字；z16 无无名圆。

**P1-2 终态分组弹窗里两个组同名：「湖玺庄园 等 2 小区」→ 组头「湖玺庄园 · 7」「湖玺庄园 · 1」。**
全市 3 个终态簇全是这种「同一个小区被归一化成两个 key」的对子：`湖玺庄园` vs `无锡市湖玺庄园57` 所在的组、`蠡湖院子` vs `路劲蠡湖院子`、`翡翠东方` vs `万科翡翠东方`。业主看到会问「怎么两个湖玺庄园」。截图 `r08-group-pop.png`。
修法：
1. 归一化（`normalize.js`）：剥「无锡市 / 本区县名」前缀（第三轮 3-5 已列）；开发商前缀（路劲 / 万科 / 融创 / 金科 / 绿地 / 建发 / 碧桂园…）剥掉后若与已有小区名相同则合并为同一 key。
2. 兜底（`openGroup`）：成员 label 相同的并成一组；若并完只剩一组，头部不写「等 k 小区」，写「湖玺庄园 · 8 个项目」；若仍多组，组头加上区分信息（原始名，如「无锡市湖玺庄园」）。

### P2

**P2-1 高德地名 / POI 文字与我们的圈、标签相压（②③级）。** 1350 z12：「无锡方圆荟购物中心」顶着 52 的「1 告警」角标，「无锡江南大悦城」与「12 小区」交叠；惠山 z12：「惠山区」区县名穿过 4·1 告警 圈；z16：「蠡湖一号售楼处」穿过 金科蠡湖 胶囊。上一轮是「同名两份」，这一轮不重名了但还是打架。建议：②级（z < 13）`setFeatures` 去掉 `point`，只留 `bg, road, building`（簇级本来就不靠地名定位，右侧面板有区县）；③④级保留 `point`，但给 `.dm-mk__label`、`.dm-mk__badge` 加 2 px 同底色描边（`-webkit-text-stroke` 或 `text-shadow` 四向），我们的字永远盖在高德字上。2560 下高德字 12 px、我们 17 px 的差距照旧（第三轮 3-1 第 5 条）。

**P2-2 标记从半透明顶栏 / 图例 / 状态行后面透出来。** 1350 z12：惠山的「16 / 3 告警」红圈正好在「点位 / 热力」分段下面；z13：「3 小区 / 2 小区」文字贴着时钟；z14：「3 宝界山庄」胶囊被左下图例盖住一半，「2 小区」被状态行文字盖住。`.topbar` 渐变 96 px 到 0，所以 50–96 px 之间的标记是半隐半现。建议：地图容器加 `mask-image: linear-gradient(#000 0, transparent)` 顶部 0–96 px 淡出（标记随底图一起消隐，不再半透），或顶栏在 0–64 px 用实底 + 64–96 px 渐变；左下图例、右下状态行给 `backdrop-filter: blur(8px)` + 0.85 底色。

**P2-3 拆分时父项角标和子项角标同屏约 100 ms（两个「1 告警」）。** 父项淡出 120 ms、子项 240 ms 飞入，前 100 ms 两份角标都可见（`sheet-split-zoom.png` 第 1–2 帧）。建议 `leave()` 时先把父项 `.dm-mk__badge` 和 `.dm-mk__label` 置 `opacity:0`（立即），圆再淡出；或父项淡出缩到 80 ms。

**P2-4 弹窗顶边落在 94 px，比 `avoid.top + 12 = 108` 高 14 px。** 三次弹窗（金科蠡湖、湖玺庄园、绿地香颂）`rect.top` 都是 94。视觉上没被挡（顶栏那里已经基本透明），但 1920 电视上顶栏更高时可能贴到时钟。查 `avoidUi` 用的 `offsetHeight` 与入场缩放 / `info.setOffset(-22k)` 的换算。

**P2-5 抖动点击告警行会选中文字。** 鼠标按下→抖 2 px→抬起 点绿地香颂行后，「今天 16:24」被选中高亮（`r09-feed-focus.png`）；电视遥控不会，触摸长按会。`.alarms li`、`.dm-pop li`、`.dm-mk` 加 `user-select: none`。

**P2-6 小目标（沿第三轮）。** 退出 63×31、详情页「返回上一页」88×29 / 「退出登录」同高、1350 下告警行 39 px（CSS 46 × 界面缩放 0.85，1920 电视上是 46，可接受）。只有前两个还低于 40。

**P2-7 1920 点滨湖区落到 z13.03、视野内 41 圈。** `zoomTo` 用 `padding(60)` 适配主体，地图区越大适配出的级别越高：1350 → 12.13、1920 → 13.03、2560 → 13.51，②级在三块屏上看起来不是同一级密度。建议点区县后的目标级别上限 `min(fit, zoomCluster() + 1.5)`（1920 → ~12.5），让「点一下区县」在三块屏上落到差不多的簇密度。

**P2-8 城市适配级别随加载时机变化。** 首次登录（数据渐进加载）城市视野 z10.14 / 1350，缓存热时 9.86（设计稿的数字）；最后一批数据到齐后没有再 fit 一次。影响只是区县圈缩小系数不同（75 vs 88 px），不用急。

**P2-9 顺带：** 详情页右侧两张「待定」占位卡仍在（线上也有）；dev 控制台有一条 vite「Module "fs" externalized」警告（某依赖在浏览器端 import fs，生产构建无影响）。

## 4. 结论

- **P0：无。** 所有点击（鼠标抖动、触摸抖动、遥控键盘路径的 Enter）都命中，没有回退、没有报错，没有口径不一致。
- **可以发。** 建议顺序：先改 P1-1（`layoutLabels` 的优先级规则 + 终态不留无名圆，半天量级），随本次发；P1-2 的兜底（`openGroup` 同名并组）也可以一起，归一化前缀剥离放下一轮；P2 按 1 → 2 → 3 → 5 的顺序排进 polish。
- 业主笔记本（1350×700）上的观感：城市视野干净，点滨湖区后 25 个圈、无相压、告警一眼可见；滚轮进到 14 级后会看到 P1-1 那个「没名字的红圈」，这是他最可能先指出来的一处。
